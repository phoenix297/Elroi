# Site build

All HTML pages (English and German) are generated by these scripts. Edit the scripts, not the HTML,
then rebuild:

```bash
pip install beautifulsoup4      # once
python3 _build/build.py         # rebuilds every English page, then the German site in /de/
```

| File | What it does |
| --- | --- |
| `build.py` | All English page content, header/footer, SEO tags, structured data, guides, sitemap, robots.txt. Runs `build_de.py` at the end. |
| `build_de.py` | Creates `/de/` from the English pages: translates text, fixes links, adds hreflang to the sitemap. Guides stay English. |
| `de_dict.py` | English → German translations. When you add or change English text, add the German here. |
| `extract.py` | Helper that finds translatable text. |
| `chart_land.txt` | World map outline for the "How it works" journey (Natural Earth, public domain). |

`build_de.py` prints any English text it could not find a translation for. Add those to `de_dict.py` and rebuild.
The site address used in canonical links, the sitemap and structured data is `SITE_URL` in `build.py`
(and in `build_de.py`); change both when the custom domain goes live.

GitHub Pages (Jekyll) does not publish folders that start with `_`, so this folder is not part of the live site.
